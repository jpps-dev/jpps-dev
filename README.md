## 📂 Projetos em destaque

### 🌎 World Cup 2026 — Retro Table Layout

Projeto acadêmico desenvolvido para praticar os fundamentos do desenvolvimento web utilizando **HTML puro**.

O projeto apresenta informações sobre a Copa do Mundo de 2026 e utiliza intencionalmente uma abordagem visual inspirada nos primeiros sites da Web.

**Principais conceitos:**

- Estrutura semântica de páginas HTML
- Tabelas
- Imagens
- Links e navegação
- Organização de conteúdo
- Publicação com GitHub Pages

🔗 **[Ver projeto](https://github.com/jpps-dev/World-Cup-2026-Retro-Table-Layout)**
